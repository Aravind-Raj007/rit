# Resume Bullet Points: CyberGuard Lite / ScamGuard Pro

## Project Description

A local-first, privacy-focused cybersecurity desktop application built to detect scams, encrypt files, and monitor network safety without relying on cloud services.

## Bullet Points

- **Developed a high-performance desktop security application** ("CyberGuard Lite") using **Electron** and **Next.js**, ensuring cross-platform compatibility (Windows/macOS) and a modern, responsive UI.
- **Architected a privacy-first, offline-only system** that processes all data locally using **SQLite**, eliminating cloud dependencies and ensuring 100% data sovereignty for users.
- **Engineered a custom authentication and security framework**, implementing **Bcrypt** password hashing, secure session management in memory, and AES-based file encryption.
- **Built advanced threat detection capabilities**, integrating **ONNX Runtime** and **OCR** (Tesseract.js) to analyze text and URLs for phishing patterns using local AI models.
- **Optimized application performance** by implementing concurrent background processing for network scanning and file analysis, maintaining a smooth user experience (under 150ms latency).
- **Designed a comprehensive dashboard** featuring real-time threat monitoring, network device discovery, and automated security reporting using **Node.js** scheduling.
